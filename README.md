# SCC403 Data Mining Project

This project explores both unsupervised and supervised machine learning techniques through two tasks: climate data analysis and pet image classification.

## Key Features
- Climate data preprocessing, feature selection, and outlier removal
- Dimensionality reduction using PCA, UMAP, and Isomap
- Clustering using Gaussian Mixture Models (GMM) and Spectral Clustering
- Deep learning image classification with ResNet18 and VGG16
- Transfer learning and feature extraction using pre-trained models
- SVM-based classification on extracted image features
- Model evaluation using silhouette scores, purity scores, confusion matrices, and classification accuracy

## Technologies Used
- Python
- Scikit-learn
- TensorFlow
- PyTorch
- NumPy
- Pandas
- Matplotlib
- Seaborn
- UMAP

## Results
- UMAP consistently produced the clearest cluster separation for climate data.
- GMM provided more reliable clustering performance than Spectral Clustering.
- ResNet18 offered excellent computational efficiency with strong accuracy.
- VGG16 achieved the highest classification accuracy, reaching up to 99% on pet image datasets.

## Datasets
- Basel Climate Dataset (2010–2019)
- Oxford-IIIT Pet Dataset
- Kaggle Cats and Dogs Dataset
